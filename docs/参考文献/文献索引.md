## 六、Top-15 优先精读（调研文档 §10）

1. HAM-CD（TGRS 2026）— baseline
2. CD-RLKNet（IJAEO 2024）— CD + reparam large kernel 直接 prior art
3. UniRepLKNet（CVPR 2024）— dilation reparam 与 TAM 高度同源
4. DBB（CVPR 2021）— 串联/跨模块折叠的数学核心
5. ASR（ECCV 2024）— 为什么 SE/attention 不能直接折
6. LKMamba-CD（2026）— Mamba + reparam large kernel + CD，最危险碰撞
7. RepViT（CVPR 2024）— 轻量部署 / latency 参考
8. OREPA（CVPR 2022）— decoder-wide Rep 训练开销的解法
9. EfficientVMamba（AAAI 2025）— SSM 轻量化边界
10. MSVMamba（NeurIPS 2024）— multi-scan 冗余
11. PVMamba（ICCV 2025）— 动态 SSM 加速的正确方向
12. DMFANet（TGRS 2025）— 差异融合强近邻
13. ST-Mamba（TGRS 2025）— spatial-temporal Mamba 近邻
14. PAT（ICCV 2025）— 异构多教师 feature KD
15. ViT-Linearizer（ICCV 2025）— Mamba/linear student 跨架构蒸馏先例
